# Dinh dưỡng Việt

MVP website tra cuu dinh duong thuc pham va mon an Viet Nam.

## Chay local

```powershell
npm install
npm run dev
```

## Build

```powershell
npm run build
```

## Deploy mien phi

Dung Cloudflare Pages:

- Build command: `npm run build`
- Output directory: `dist`

Du lieu ban dau nam trong `src/data/nutrition.ts`.
